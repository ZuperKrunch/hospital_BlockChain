Guide line cara pakai :
1. Siapin akun meta mask dan harus bikin contract sendiri sih kalo mau jadi admin
2. Copy aja semua file dari git lalu bikin file .sol baru di remix anda pake file yang kami sediakan di folder contracts
3. Kalau udha copy isi .sol tinggal compile dan pastikan anda pilih browser extension trs pilih meta mask di bagian compiler 
4. Bikin akun meta mask atau pake aja yg udah ada, akun yang pertama kali akses contract yg kamu compile & run tadi bakalan jadi admin
5. Bikin aja 2 atau 3 akun dummy lagi tinggal pencet accounts diatas kiri lalu add acccount buat jadi pasien/dokter.
6. jangan lupa ambil sepolia dari faucet yang disediakan google tinggal masukkin address admin atau siapa bebas 
7. Kalo udah semua waktunya set role ke akun akun dummy yang dibuat tadi pake akun admin (jangan lupa pilih sepolia baut penukarannya)
(Kalo belom sepolia anda harus ke netowrks dibawah lalu pencet manage networks disana ntar nyalain test networks lalu sepolia bakal muncul)
8. Selesai set role udah deh bisa dicobain fitur fiturnya 
dokter : lihat record pasien, edit record pasien, delete record pasien (perlu izin pasien)
pasien : ngasih izin ke dokter mana yang boleh liat record dan bsia liat record dia sendiri, bisa cabut izin juga dan cek izinnya dulu jadi ga dobel biar rapih aja
admin : cuman nagsih role ke akun akun yang ada

jangan lupa semua akun-akun perlu sepoliaETH jadi dr akun admin tadi di giveawway ke akun akun lainnya sekitar 0.00100 cukup
